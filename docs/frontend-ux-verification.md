## 第三轮：减少引导与长报告阅读

本轮沿用既有设计方向，只修改 Vue 展示组件、模板、CSS、示例文案、前端回归及界面文档。不改后端、接口、依赖、资料策略、鉴权、审核与任务编排。移除展示 import 与新增加的展开详情辅助函数后，`App.vue` 脚本与上一提交一致；默认 `internal`、模式值、事件处理与权限条件均保留。

### 页面变化

- 首页删除重复的能力行与静态底部提醒，只保留动态范围说明；两个示例换为课程比较、远程办公，仍调用原来的填入函数，不自动切换范围或提交任务。研究模式值不变，仅将“自动选择”解释为“自动判断研究方式”。
- 手机缩减辅助文字和输入区留白；发送按钮增加可见文字，三尺寸仍保留输入、附件、模式选择和导航。没有通过隐藏关键资料策略来换取紧凑。
- 新增独立的 `ReportReader.vue`，只处理已经由原有函数净化过的 HTML。研究与正式报告均限制正文行宽；为原有二、三级标题补充唯一位置标识，保留作者已有锚点；至少三个标题才显示目录，重复标题也能正确跳转。目录随阅读滚动保留，点击后关闭并将焦点放到对应标题。
- 表格、代码保留原内容并在局部滚动；实际溢出的表格显示滑动提示，宽度变化时重新判断。目录与辅助提示不进入原始 Markdown 或下载文件，不加入模型摘要。
- 顶部“核验与用量”“版本与审核”可直接展开对应详情并定位；展开标题说明所含字段。过程、来源系统标识和检索分数分别使用更明确的入口名称。质量风险、未回答问题与原文不可访问提示仍公开展示。

真实账号场景仍覆盖 OIDC、偏好保存与删除、导出、资料生命周期、任务幂等/取消/SSE、双人审核及权限；没有用阅读替身代替真实链路。三个额外付费公开研究用例未在本地开启。

### 用户视角复核

本轮重点是降低操作和阅读负担，未更换视觉品牌。需要检查首页说明是否减少、手机首屏是否可开始、长文中途能否切换章节、技术字段是否仍能找到。保留专业工具的克制风格，不把没有装饰或动效视为缺陷。更长且没有规范标题的报告不会凭空获得目录；阅读效果仍受报告自身结构影响。

# 纸桥个人知识库：第一版需求

**合成演示资料。** 项目、人名、日期、数量和测量记录均为虚构，用于验证研究工作台如何比对资料，不是 DeepResearch 或任何数据库的性能结果。

记录日期：2026-11-13。文档版本：需求 v0.4。维护人：演示用户小桥。

纸桥是一个供个人使用的技术笔记库，第一版在一台 4 核、16 GB 内存的电脑运行，最多同时打开 3 个客户端。2026-11-13 的导入清单有 1,200 份 Markdown 笔记，切分后是 9,600 个文本块；约一半内容为中文，其余是中英混排。它们不是 9,600 份文档。

两类常见查询是“ERR-Q17 的处理记录在哪里”和“机器重启后索引为什么没有恢复”。前者需要找到编号，后者经常用不同说法描述同一问题。第一版必须保留来源文件与段落位置，并支持按项目筛选。删除笔记后，搜索结果不应继续显示其正文。

目标是先交付可维护的个人工具，不是承诺高并发服务。第一版只处理可提取文本的 Markdown；扫描 PDF、图片 OCR 和多人权限不在第一版范围内。笔记中可能含私人内容，公开搜索默认关闭；这不代表调用模型时文本不会发给模型供应商。

候选路线有两条：甲是关键词检索，乙是关键词与向量结合的混合检索。第一版可以先交付甲并保留后续升级入口，但是否采用乙，要结合试验记录、维护成本和未验证项判断。本需求没有指定数据库产品，也没有测出真实硬件容量上限。

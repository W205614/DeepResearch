# MinIO / Silo 的本次修补范围

2026-11-13 的本地候选同时处理原始 34 条 LOW/MEDIUM 操作系统记录，以及完整补充扫描发现的 curl、Thrift 记录。它还不是已发布版本或日常环境切换记录。

原始 34 条按完整 CVE、包名、安装版本、严重级别和扫描目标逐项对应，不能只按数量判断通过：

| 处理 | 原始记录数 | 实际依据 |
| --- | ---: | --- |
| 签名软件包更新 | 17 | 三个 glibc 包更新至 `2.34-290.el9_9`，libgcc 更新至 `11.5.0-17.el9_9`；保留 Red Hat 修复记录、完整 RPM 库存、签名核验和新扫描。 |
| 源码修复 | 4 | glibc 的 LANGUAGE 路径检查对应三个包记录；实际重建并替换 libc 和 loader。另修复真实存在于 libtic 的 terminfo 解析问题；没有因为镜像缺少 tic 命令而排除该库。 |
| 精确组件或架构不适用 | 13 | 分别核对旧 coreutils 的实际实现、缺失的 BIG5-HKSCS 模块、Power8 专用实现与实际 x86_64 ELF、libgcc 与 libstdc++/libiberty 的边界、ncurses 数据包以及不在镜像中的 pcre2test。 |

[34 条逐项矩阵](../deployment/security/minio-os-20261113-evidence/os34-dispositions.json)提供原始完整记录、一手来源和文件摘要。后两类共 17 条仍出现在原始扫描中；没有修改严重级别、丢弃记录或声称零漏洞。源码修复验证包括正常输入、完整导出 ABI 和原有加固属性的核对，不等于执行了恶意漏洞复现。

补充完整扫描发现静态 curl `8.22.0` 的 21 条记录和实际编入 Silo 的 Thrift `0.24.0` 的 5 条记录。这些组件确实存在，不能靠系统 glibc 升级或依赖名称判断排除。候选实际构建 curl `8.23.0` 和 Thrift `0.25.0`；固定源归档、签名、模块摘要、完整依赖图和实际二进制证明版本变化，新完整扫描中这 26 条记录消失。curl 同时记录 zlib、Brotli 构建依赖的实际变化，没有声称只改了 curl 一个文件。

当前准备候选的完整 Trivy 报告保留 24 条记录、secret 0 条；完整 Grype 报告保留 23 条。除上述 OS 记录外，Go 模块记录继续按实际编译闭包及原始一手证据逐项复核。新安全门槛绑定完整文件清单、全部严重级别、完整包库存和实际镜像身份，新增、缺失或改变的记录都会阻断。RPM 数据库只允许四个签名升级包的安装时间及事务 ID 差异；其他表、字段、头部字节和应用元数据都参与核对。

Syft 的包、许可及二进制识别位置都包含镜像层身份。真实正常重建曾因嵌套层 ID 改变被旧消费者阻断，原失败保留。新消费者逐个核验这些位置属于实际镜像的有序层，再按层索引比较；不删除嵌套字段、许可或位置对象。三份实际完整报告的 392 项库存一致，未知层、位置移动和其他元数据变化仍会失败。这项消费者修正另有两份独立续审，原物理制品审查和编译输入身份不被改写。

静态 curl 仍包含 OpenSSL `3.5.9`。扫描器没有把嵌入库单独报告出来，不代表库已修复。另行核对五个已知上游条件，结论仅适用于固定 curl CLI 的当前 TCP TLS / SSH 路径及当前服务入口：不使用 CMS 加密、AES-GCM-SIV 或原生 QUIC。不能扩展为任意插件、回调、外部程序或未来构建安全，也不声称受影响函数从静态库中消失。MinIO 的 Compose 健康检查实际使用 `silo healthcheck`；额外 curl HTTP 检查是独立的正常工具验证。

正常 S3 验证覆盖就绪、对象读写、版本和 multipart。S3 Select 的 Parquet 功能在当前上游默认关闭：原默认请求的失败保留，另在独立测试容器按上游文档开启 `MINIO_API_SELECT_PARQUET=on` 后验证正常 Parquet 查询。没有为让测试通过更改镜像默认配置或日常配置。

新配方和对应源码属于源码交付材料；本轮没有批准发布第四个 MinIO 二进制镜像。[固定输入](../deployment/security/minio-os-20261113/source.lock.json)包括构建工具和依赖的真实来源，不代表全部二进制输入都可以直接复制到公开附件。新版本材料只收录核实过的对应源码、补丁、许可、构建配方及来源索引；历史构建仍需要的五个辅助来源 Release 继续保留，详见[迁移依据](release-asset-migration-20261113.md)。最终组合、真实模型复验、CI 和公开发布状态以版本页及后续验收收据为准。

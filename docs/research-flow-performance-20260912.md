# 研究流程优化与真实耗时对比

同一题目的原始运行耗时 214.016 秒，最终优化版 139.344 秒（约 2 分 19 秒），本次观察减少 74.672 秒、约 34.9%。

**这不是可保证的提速比例**：每版只有一个真实样本，搜索结果、模型输出和网页缓存不同；原始与首版运行均执行三轮检索，最终版执行两轮。最终版仍是 deep，补搜上限仍为两轮，没有改为 quick。

## 实现变化

1. 搜索由串行改为最多 3 个并发，网页读取由 3 个改为 6 个并发；保留候选覆盖、原子配额和可取消性。
2. 核验通过来源 ID 引用去重后的完整原文，每条结论保留自己的来源范围，不截短原文。
3. 分析输入完全一致时复用该任务的分析结果，输入改变时重新计算。
4. 修订仅返回失败结论的替换或删除，不再重写整篇；程序保留已通过内容，并重新核验修订结果。未知引用、重复索引和未保留结论不会发布。

## 固定输入的结构性收益

使用原始运行相同的 13 条已发布结论和 7 份原文构造核验请求：重复内嵌格式为 176,255 字节，按来源 ID 去重后为 71,867 字节，减少 59.23%。这是同一输入下的请求体字节数比较，不是 tokens 或端到端速度指标。各份原文的哈希保存在 payload-comparison.json。

## 验证与边界

- 相关回归测试 88 项通过，Ruff 和 git diff --check 通过。
- 最终版使用真实模型运行 conflict-1、negation-2、injection-1，三项均通过；这是固定证据的聚焦评估，未重跑完整 30 项质量集，也不是独立人工评审。
- 最终真实报告保留 15 条结论、排除 27 条，状态 completed；不能据此宣称完整性或准确率得到提升。
- 独立临时账号没有本地文档，因此不代表包含大量本地资料的性能。
- 三次运行均未超过 300 秒令牌有效期，不能用于证明自动续期。
- 代码已更新到本机 backend 与 worker；未推送 Git。

# README 截图来源与边界

首页复用仓库已有页面截图，没有为本组素材重新启动日常环境或采集新业务资料。画面使用 `research-demo`、研究体验工作空间和“展示样本”等合成内容；它们与本轮另外执行的隔离浏览器回归、两次官方 API 探针不是同一批输出。

| 文件 | 展示内容 | 已核对来源 |
| --- | --- | --- |
| `workspace.png` | 资料范围、研究输入和导航 | 当前文件最后变更于 `d730c1b710064fe87d1081de180163140f702215` |

这些是实际界面的历史截图，不是实时在线演示，不证明图片中的报告由本轮真实模型生成，也不代替权限或部署验收。原截图的完整执行命令没有随 PNG 保存，不能仅凭文件名恢复当时全部环境。

仓库保留相关画面的自动化入口：

- [visual-ux.e2e.ts](../../frontend/e2e/visual-ux.e2e.ts)：不同宽度的登录、工作台、资料与阅读界面；部分用例使用页面路由替身，临时 OIDC 账号用例由企业测试器提供。
- [report-live.e2e.ts](../../frontend/e2e/report-live.e2e.ts)：真实 OIDC／Java／PostgreSQL／前端审核链，使用确定的已完成研究数据，避免把固定文本当作模型研究结论。
- [reading-report.ts](../../frontend/e2e/fixtures/reading-report.ts)：人工编写的长文排版样本，源码明确标记为展示夹具。

上述测试支持 `E2E_SCREENSHOT_DIR`；重新采集应使用项目约定的隔离环境、合成账号和数据，不将日常库当作截图夹具。不声称这些入口能逐像素重建历史 PNG。

正式 `v0.1.3`（工程提交 `78a19df9dfa6f072af6ebe40ff99cf164d0c4ff8`）的隔离核心浏览器 4 个用例使用模型夹具，均通过、0 跳过；实际 Packages 拉取与普通端口日常验收另行完成。两次官方 API 契约探针（合成文本 JSON、3072 维 Embedding）实际发生于 2026-11-10，新版本复用同一未变化 Agent 制品的结果，本阶段追加调用 0。这些结果没有被合成为 PNG 中的报告，也不改变旧图来源。历史供应商结果见[2026-11-08 日常验收](../evidence/daily-20261108/README.md)，当前交付见[版本记录](../delivery-history.md#2026-11-11-v013-正式交付)。模型、业务、负载和界面证据分别按实际范围解释。

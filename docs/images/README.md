仓库保留相关画面的自动化入口：

- [report-live.e2e.ts](../../frontend/e2e/report-live.e2e.ts)：真实 OIDC／Java／PostgreSQL／前端审核链，使用确定的已完成研究数据，避免把固定文本当作模型研究结论。

上述测试支持 `E2E_SCREENSHOT_DIR`；重新采集应使用项目约定的隔离环境、合成账号和数据，不将日常库当作截图夹具。不声称这些入口能逐像素重建历史 PNG。

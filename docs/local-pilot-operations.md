## 值守时使用

从项目根目录运行只读检查：

```powershell
.venv/Scripts/python.exe scripts/verify_local_deployment.py
docker compose ps
```

检查核心服务、数据库版本、权限入口、外发开关和监控采集情况；不调用真实模型、不发送通知。脚本当前针对本机默认 8080 端口和本次迁移版本，后续升级时需同步调整。

Grafana 入口为 http://localhost:3000，Alertmanager 为 http://localhost:9093。本轮没有主动发送外部告警，不能宣称值守人已经收到通知。Prometheus 位于 Docker 内网。

出现模型阻断先核对错误码和服务配置；预算耗尽的任务不得通过反复恢复清零。文档队列异常先检查独立文档 Worker。数据库故障先停止新写入并保留数据，不清空卷重建。磁盘不足先确认可删除的是缓存或过期日志，不删除数据库、附件或唯一备份。

新冷备需要维护窗口，先等待任务结束，再执行：

```powershell
./scripts/backup.ps1
./scripts/restore.ps1 -BackupPath <本次备份绝对目录>
```

备份会短暂停止服务，因此本轮没有擅自添加定时停机备份。恢复脚本只允许新建隔离项目，禁止覆盖原卷。本轮备份与原系统在同一主机，无法抵御本机磁盘丢失。

# 恢复、保留与检索运维合同

本轮源代码和离线验证分别见 `reliability.json`、`retrieval.json`、`verification-boundary.json`。这些记录不替代最终提交的组件验收和 CI。

## 任务恢复

Java 新调度和恢复命令携带 `research-command-v1` 与 `expected_attempt`；历史仅含 `resume` 的 Outbox 命令仍可回放。命令版本、严格字段和执行代次在 Python 适配器及 Worker 抢占时校验。恢复保留已消耗调用、token 预留、累计时限和失败历史；检索故障导致研究图已到终点时重新研究，节点中断仍从检查点继续。基础设施心跳异常为可有界恢复的 `interrupted`，不能伪装成用户取消。

## 上传与替换

首次上传在存储前持久记录扫描任务。完整隔离原件在校验哈希后重新扫描；缺少原件时明确要求重传；扫描拒绝、扫描次数耗尽都不能进入索引。上传主体在存储前记录，恢复索引仍归属原费用主体。

替换保留旧 `ready` 版本，在写入隔离对象前持久记录清理归属。替换预处理取消或进程退出后，管理员可依据记录定向清理并重传；这不宣称替换自动续扫。成功提交为待发布版本后，清理器保护该对象直到索引切换。异步线程中的存储写入、移动和删除完成后才向调用方传播取消，避免晚写、晚删越过锁和墓碑。

## 删除、保留与归档

显式删除会话与清理研究数据在 SQL 事务中处理研究产物、死信等关联记录，再凭 `run_cleanup` 重试外部检查点及附件清理。正式报告或修订审计引用的源任务受保护。独立保存的个人偏好和语义记忆按原合同保留，应通过独立记忆管理操作删除。

自动过期只清理限批网页缓存、检索缓存和没有源任务的历史孤儿产物。文档版本、正式证据、事件和检查点默认不按天数自动删除。`RETENTION_ARCHIVE_AFTER_DAYS` 默认 0；开启后复制带哈希的不可变研究归档并保留原件，不能把它称作异机归档或磁盘回收。

## 大语料升级前回填

执行数据库迁移后，应在开放研究接单前运行派生词法回填。镜像中需包含脚本；以下命令使用已经配置迁移数据库身份的短生命周期服务，不调用模型、嵌入、向量或对象存储：

```powershell
docker compose run --rm --no-deps migrate python scripts/rebuild_lexical_index.py --all-workspaces --max-batches 10000
```

日常部署操作仍须遵守本轮共享部署窗口、备份和恢复原状态要求。脚本每 32 行提交一次，每 10 批输出进度；退出 0 表示完成，退出 2 表示需继续执行。重复运行跳过已有投影，不重置已完成工作；缺少当前管理员的空间不会被默认为完成。

原 4000 片段内存限制不再意味着资料超过该值就整体不可检索。小语料保持原 BM25 排序；较大语料由数据库统计、评分并返回有限候选，向量命中和相邻原文仍回 SQL 校验当前权限。新上传由文档数与总片段准入限制控制。实际 PostgreSQL 查询计划、资源余量及最终部署响应仍需组件验收，固定中文题集和 SQLite 内存探针不提供生产容量承诺。

## 本次修复

- **长网页读取**：原实现把正文压平并只保留前 10,000 字符，可能遗漏规范后面的定义。现保留段落及预格式化代码块的缩进和字符串空格，提供已下载大小上限内的完整正文；下载上限仍为 1.5 MB，DNS、重定向、正文类型等检查保持有效。
- **选段完整性**：已经选取完整段落时不再按最后一个分隔符二次裁剪，避免英文末段丢失。模型上下文仍按原来的 UTF-8 字节预算选段，并明确标记省略。
- **缓存升级**：使用新的网页读取缓存标识，旧前缀缓存首次访问时重新读取；不改写历史报告或已冻结证据。重新核查网页时，采集规则改变也可能导致内容散列变化，不应直接推断网页本身发生变化。
- **超长来源核验**：保留短来源的完整输入；单条超长来源按结论选取有明确省略标记的完整段落，并为核验目标预留上下文。独立评分器也处理单来源超限，不提高上下文上限，不把选段缺失当作全文不存在，不把选段核验声称为全文核验。
- **拒答用例**：`no-evidence-refusal` 同时接受“资料”和“证据”，保留零事实与明确拒答说明要求，新增缺少说明、无关回答和编造事实的反例。旧的 0/3 或 9/10 判定不覆盖成新成绩。

本轮未新增依赖、数据表或 Alembic revision。此前已修复的迁移计数序列化、报告局限丢失、终态任务收尾取消问题保留。局部自动检查为 80 项通过，Ruff 通过；最终提交的 CI 另行核对。不同阶段的结果分别报告，不合并成一次全套通过或通用准确率。

首个候选提交的 CI 有 6 项静态预算证明检查失败：核验函数与拒答用例改变后，原绑定指纹已过期，检查按设计拒绝通过。重新审查三处函数与用例后同步当前证明，245／296 的必要下界及 CI 额度、累计账本、四条付费调用入口和阈值均保持不变；新增关联检查 36 项通过。该次失败保留，最终提交重新执行 CI。本轮没有触发手动付费 CI。

## 复现入口

- `scripts/evaluate_research.py`：固定研究、`eval/research_quality_extensions.json` 和 `eval/live_research_cases.json`；参数见该脚本 `--help`。

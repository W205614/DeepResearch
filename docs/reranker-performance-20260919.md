# Reranker 默认开启与链路实测（2026-09-19）

## 结论与边界

正式 Compose 栈默认启用 SiliconFlow `Pro/BAAI/bge-reranker-v2-m3`，使用完整 `/v1/rerank` 地址和字符串文档协议；密钥只通过部署环境注入。真实检索对照与本地资料答案门禁均通过，隔离控制面压测中的限流、舱壁和熔断按预期生效。

以下数据来自单机固定语料或固定夹具，不代表生产 SLA、任意知识库准确率或真实模型并发容量。一次三候选探针中，重排模型曾把词面重叠较高的错误描述排在正确描述之前，因此仍需保留融合回退、引用核验和固定困难集回归。
